# Dongha Kim — Personal Homepage

GitHub Pages에서 바로 열리는 정적 개인 홈페이지입니다.

## 제출 전 바꿀 내용

1. 이메일을 공개하려면 `index.html`의 `Email available on request` 문구를 공개 가능한 주소로 바꿉니다.
2. 저장소 이름을 반드시 `GitHub아이디.github.io`로 설정합니다.
3. `index.html`, `DESIGN.md`, `README.md`를 저장소의 최상위 폴더에 올립니다.
4. GitHub의 **Settings → Pages**에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다.

완료 후 `https://GitHub아이디.github.io`에서 확인할 수 있습니다.
